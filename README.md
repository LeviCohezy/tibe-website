# TIBE — ADHD-fueled urban design

Portfolio/brand site voor Tibe. Next.js 15 (static export), Tailwind 4, GSAP, Framer Motion.

```bash
npm run dev          # lokaal op http://localhost:3000
./deploy-pages.sh    # build + push naar gh-pages
```

- Productdata en contact-e-mail: `lib/data.ts`
- Beelden: `public/img/` (product zonder beeld toont automatisch een zilveren placeholderkaart)
